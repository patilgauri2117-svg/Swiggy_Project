📌 Project Overview

Swiggy Food Delivery is a web-based application inspired by the popular Swiggy food delivery platform. It aims to provide users with a convenient way to explore food options and place food orders through an online interface.

The project is developed as a web development project using frontend technologies and PHP with MySQL database integration.

✨ Key Features
🍕 Food delivery website interface
🔍 Browse available food items
🛒 Online food ordering interface
👤 User-friendly website design
🗄️ MySQL database integration
📱 Responsive and easy-to-use interface
🌐 Live website deployment

Features depend on the functionality implemented in the current project version.

💻 Installation and Setup

Follow these steps to run the project locally.

1. Clone the Repository
bash
git clone https://github.com/patilgauri2117-svg/Swiggy_Project.git

2. Open the Project
bash
cd Swiggy_Project

3. Setup XAMPP
Install and open XAMPP.
Start Apache and MySQL.
Copy the project folder into the htdocs directory.
4. Setup Database
Open phpMyAdmin: http://localhost/phpmyadmin
Create a database for the project.
Import the provided food_delivery.sql file.
Update the database connection settings in your PHP configuration file.
5. Run the Project

Open your browser and visit:

text
http://localhost/Swiggy_Project/
